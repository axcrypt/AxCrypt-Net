# Support

## Where to get help

- **Documentation**: [README.md](README.md), [BUILDING.md](BUILDING.md),
  [docs/CLI.md](docs/CLI.md), and the AxCrypt help center at
  https://axcrypt.net/helpcenter/.
- **Questions about building or using this source code**: open a GitHub
  Discussion (if enabled) or an issue using the appropriate template.
- **Bugs**: open a [bug report](.github/ISSUE_TEMPLATE/bug_report.yml).
  Never attach encrypted files together with their passwords, and never
  post passwords or key files.
- **Security vulnerabilities**: do **not** open a public issue — see
  [SECURITY.md](SECURITY.md) for private reporting.

## Commercial support / official apps

AxCrypt AB offers the official, signed AxCrypt applications and
account-based services (subscriptions, mobile apps, support) at
https://axcrypt.net. Issues with AxCrypt AB accounts, subscriptions, or
official store builds are handled by AxCrypt AB support at
https://axcrypt.net/support/, not in this repository.

## Scope

Maintainers prioritize: reproducible bugs in this code base, security
reports, and well-scoped feature discussions. Best-effort support only for
community builds on untested platforms.
